# Changelog

All notable changes to this project will be documented in this file.

The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.1.0/),
and this project adheres to [Semantic Versioning](https://semver.org/spec/v2.0.0.html).

## [0.1.0] - 2026-11-14

First release in the Nextcloud app store.

### Added
- Grocery lists with items and quantities
- Categories with colors, in an order you set by drag and drop
- Drag items between categories
- Check off items, or snooze an item for 15 minutes
- Show only unchecked items, or an A–Z list with a letter index
- Share lists with other users
- Unchecked item counter per list in the navigation
- Support for Nextcloud 33 to 35
